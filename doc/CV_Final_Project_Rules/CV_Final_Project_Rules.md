2.所有組別請於 6/1 23:59 前寄送最終程式碼到助教信箱 [fushengyu@media.ee.ntu.edu.tw](mailto:fushengyu@media.ee.ntu.edu.tw)

內容需有 python code,以及一個文字檔(.txt) 講解程式怎麼跑 (怎麼放置檔案、怎 麼執行 command line、目前跑出的數據)。最終程式碼成績會看這次繳交的程式 碼打分。遲交程式碼以零分做計算。

- 3.助教會於 6/2 提供 2 組 hidden sequences,請所有組別用 6/1 23:59 前繳交的最 終程式碼跑剩下兩組數據。
- 4. 所有組別請於 6/5 23:59 前寄送一份書面報告和一份投影片報告到助教信箱。 報告跟投影片的結果請出示 4 隻之前給的 sequences 平均結果和 6 隻 (原本的 4 隻+ hidden 的 2 隻)的平均結果。請將數據結果放在書面報告跟投影片報告的前 幾頁。遲交報告以零分做計算。

# Stereo Matching Team

### 一、作業規範:

- 1.請到 NTU COOL 下載題目所需檔案
- 2.在自己電腦上可以跑一組圖的模擬結果,在 codalab 上面可以跑三組圖的結果 (含原本的一組圖),最終成績以四組圖(三組圖+一組 hidden 圖)的結果計算。 Codalab 網址稍晚公布
- 3.作業環境請以 python3.8 運作,可安裝套件如助教提供的 requirement.txt
- 4. 所需語法如下 python3 main.py --image Teddy python3 eval.py --image Teddy

#### 二、繳交作業格式規範:

1.所有組別請於 6/1 23:59 前寄送最終程式碼到助教信箱

### [fushengyu@media.ee.ntu.edu.tw](mailto:fushengyu@media.ee.ntu.edu.tw)

內容需有 python code,以及一個文字檔(.txt) (放目前跑出的數據)。最終程式碼成 績會看這次繳交的程式碼打分。遲交程式碼以零分做計算。

- 3.助教會於 6/2 提供一組 hidden 圖,並公布在助教電腦上跑所有組別的成績結 果。
- 4. 所有組別請於 6/5 23:59 前寄送一份書面報告、一份投影片報告、加分題的程 式碼以及一個文字檔(.txt) 講解加分題程式怎麼跑 (怎麼放置檔案、怎麼執行 command line、目前跑出的數據)。

報告跟投影片的結果請出示 6/2 助教幫你跑的模擬結果。請將數據結果放在書面 報告跟投影片報告的前幾頁。請於報告及投影片解釋加分題的內容,可拍影片展 示結果。

遲交報告以零分做計算。
