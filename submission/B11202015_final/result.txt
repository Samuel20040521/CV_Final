== Algorithm summary ==

Single-file implementation in computeDisp.py. Standard Middlebury 4-step pipeline:

1. Cost computation:   9x7 Census transform + Hamming distance,
                       both L->R and R->L cost volumes.
2. Cost aggregation:   per-disparity-slice guided filter
                       (radius=7, eps=1e-3), color-image guide.
3. Optimization:       per-pixel winner-take-all (argmin over disparity).
4. Refinement:         left-right consistency (threshold=1) ->
                       scanline hole fill (left/right min, max_disp pad) ->
                       weighted median filter (radius=15).

Allowed cv2.ximgproc primitives used: createGuidedFilter, weightedMedianFilter.
Does NOT use cv2.StereoBM, cv2.StereoSGBM, or any other built-in stereo solver.
No deep-learning components. No custom C extensions.
