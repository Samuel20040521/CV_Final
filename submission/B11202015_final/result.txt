== Algorithm summary ==

Single-file implementation in computeDisp.py. Standard Middlebury 4-step
pipeline with two speedups and one quality refinement:

1. Cost computation:   9x7 Census transform + Hamming distance.
                       Uses numpy.bitwise_count (numpy >= 2.0, ~15x faster than
                       the per-byte popcount LUT path; LUT fallback retained).
2. R-direction cost:   Reindex from the L cost volume — cost_R[d,y,x] =
                       cost_L[d,y,x+d] with column clamp. Skips an entire
                       Hamming pass (~30% time saving).
3. Cost aggregation:   Per-disparity-slice guided filter
                       (radius=7, eps=1e-2), BGR image as guide.
4. Optimization:       Per-pixel winner-take-all (argmin over disparity).
5. Refinement:
   a. Left-right consistency check (threshold = 1).
   b. Scanline hole fill: min(nearest-valid-left, nearest-valid-right),
      max_disp padding at boundary.
   c. Parabolic sub-pixel disparity from the 3 cost samples around argmin.
   d. Weighted median filter (radius=15) in scaled uint8 space — disparity is
      stretched to [0, 255] before WMF so the median has sub-pixel granularity;
      scaled back and rounded after.

Allowed cv2.ximgproc primitives used: createGuidedFilter, weightedMedianFilter.
Does NOT use cv2.StereoBM, cv2.StereoSGBM, or any other built-in stereo solver.
No deep-learning components. No custom C extensions.
